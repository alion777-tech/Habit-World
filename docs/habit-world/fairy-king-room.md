# 精霊王の部屋

妖精の部屋の木製メニュー「精霊王の部屋」から入ります。既存の部屋、育成、ショップ、冒険の処理はそのままです。`public/opening/spirit.jpg` を表示し、森と緑・金色のデザインを引き継いでいます。

## 会話の流れ

ランダムな挨拶 → 「精霊王に今日のお言葉をいただく」または「精霊王に悩みを聞いてもらう」 → 回答。相談は「やる気が出ない」「続かない」「結果が出ない」「サボってしまった」「夢を諦めそう」の5項目です。

お言葉は15件あり、「言葉」「説明」「今日の小さな一歩」を表示します。相談は各10件、合計50件あり、やさしい回答と具体的な小さな行動を表示します。回答後は、同じ悩みへの別回答、別の相談、お言葉、最初の会話へ進めます。ヘッダーから妖精の部屋に戻れます。

プールごとに直前の文章を抽選から除外します。相談を切り替えたり妖精の部屋に戻ったりしても、部屋コンポーネントが開かれている間は抽選履歴を保ちます。ページ再読み込み時は履歴をリセットします。

## 文章を追加する

マスターデータは `data/fairy-king-dialogue.json` です。APIやAI生成は使いません。

| キー | 内容 | 追加する項目 |
| --- | --- | --- |
| `greetings` | 入室時・最初の会話に戻る際の挨拶 | 文字列 |
| `consultationPrompt` | 相談項目を選ぶ際の精霊王の台詞 | 文字列 |
| `fairyKingWords` | 今日のお言葉 | `id`, `word`, `explanation`, `action` |
| `fairyKingAdvice` | 相談カテゴリー | `id`, `label`, `choice`, `responses` |
| `fairyKingAdvice[].responses` | 相談回答 | `id`, `reply`, `action` |

`id` は重複しない安定した名前にします。`choice` はユーザーの自然な返事、その他の文章は精霊王のやさしい口調にします。`action` は今日試せる具体的な行動を提案します。達成していない習慣への達成記録を促す文章は避け、休みや準備はその事実をメモする形にします。

## 実装と確認

- `app/components/FairyKingRoom.tsx`：会話状態・選択肢・画像・フォーカス管理
- `app/components/FairyKingRoom.module.css`：既存の雰囲気に合わせた会話画面と狭い幅への対応
- `lib/fairyKingDialogue.ts`：マスターの型と連続重複を避ける抽選
- `app/components/FairyChamber.tsx`：部屋への入口・抽選履歴・元の部屋への復帰

`npm run test:fairy-king` でデータ量・IDと文章の重複・すべての回答の抽選到達性・5カテゴリーと再相談・お言葉の説明と行動・戻る操作を確認できます。データを増やす場合も、最低15件のお言葉と各10件の相談回答を保ちます。

ブラウザーでは `node scripts/preview-wardrobe.cjs --port=3001` を起動し、`http://127.0.0.1:3001/?entry=room&scenario=qa` から確認できます。この既存の確認用画面は実アカウントの処理を使いません。
