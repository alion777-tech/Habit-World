# 髪型統合・肌と顔の描画分離

## 初期の髪型

- `hair:starter-short` は旧ショップの `hair-short.png` と配置を使用する。
- ショップの `hair:short` と `hair:bob` は商品表・一覧から除外。
- 旧保存データの short / bob は starter-short / starter-bob に読み替える。所持品、装着、上下位置、拡大率、髪飾りとの組み合わせ位置を引き継ぐ。
- 旧商品の購入履歴も引き継ぐ。ブラウザーの保存内容を初期化する必要はない。

## 肌と顔

`base-layer.tsx` の SVG マスクで、元画像の肌色領域と顔・輪郭の領域を描画時に分離する。肌側にだけ肌色フィルターを適用する。顔を描き直さず、同じ画像の同じ座標を使う。

白目・瞳・眉毛・輪郭・ピンクの頬は元の色を維持する。クローゼット、試着室、一覧の基本パーツ、妖精の部屋、自律移動キャラクターで同じ描画を使う。

マスクは現在の4つの基本パーツの配色に合わせてある。新しい色調の基本パーツを追加する場合は、肌と顔の境界も確認する。新素材を制作するときは、同一サイズ・同一座標の「肌だけ」と「顔だけ」の透過画像で受け取ると、色の判定が不要になる。

検証: `node scripts/test-wardrobe.cjs`、`node scripts/test-shop-config.cjs`、`node scripts/test-shops.cjs`、`npx tsc --noEmit`。
