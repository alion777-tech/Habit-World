# アバタール・クローゼットと衣類店の試着室

## 確認方法

- 本体: `npm run dev` → `http://localhost:3000/ja`。既存のテストアカウント・テストモードで妖精の部屋を開く。
- 妖精の部屋 → クローゼット: 所持品だけを表示。
- 妖精の部屋 → アイテムショップ → 妖精の衣類店 → 試着室: 販売品を表示。
- テスト管理メニューにも `/avatar` と `/avatar?entry=shops` の入口がある。
- アカウントを使わない独立した画面確認: `node scripts/preview-wardrobe.cjs` → `http://localhost:3001`。実際のコンポーネントを使用し、Firebase・認証処理は実行しない。確認用の所持品は別ポートのローカル保存のみ。本体の認証制御は変更しない。

## 画面と導線

左は選択を即時反映する合成イラスト、右はカテゴリ別のパーツ画像のみ。名前はアクセシブルなラベルとツールチップで提供する。
クローゼットと試着室は入口で決まり、内部に切り替えボタンを置かない。
衣類店だけに試着室を設け、エルフ店とドワーフ店は将来の商品用とする。
3店とも指定の店舗画像を使用し、店員をクリックすると店舗ごとのセリフを「話しかける」ボタンの位置に表示する。クリックごとに2種類のセリフが切り替わり、音声は使用しない。

## データ

`wardrobe.ts` のカタログに基本4種、髪8種、髪飾り10種＋なし、衣装14種、羽7種。肌色7種、髪色6種は独立した配列。
`Appearance` は base/hair/accessory/outfit/wings/skinColor/hairColor/name を保持する。カテゴリ選択は対象のキーだけを変更する。
初期所持品は基本パーツ全種と、初期フォルダーの2体を参考にしたショート・ボブ、若草服・ピンクドレス、触角、虹色の羽、飾りなし。
最初は `closetPurchased:false`。妖精の衣類店で2段階の会話を読み、無料のクローゼット購入でクローゼットと試着室を解禁する。購入前は直接着替え画面を開いても案内画面になる。購入は冪等で、追加課金やポイント消費はない。
既存v2データは所持品と姿を維持し、クローゼット購入状態がなければ未購入として扱う。購入時に新しい初期パーツを追加する。
着替え商品とクローゼットの初期価格は無料。価格と販売状況は [店舗設定表](shops/README.md) から変更できる。購入は所持品に追加するだけで、保存済みの姿は変更しない。所持していないアイテムを含む姿は保存できない。
保存キーは `habit-world.wardrobe.v2:<uid>`。試着状態と保存済みの姿を分離し、ストレージ保存の成功後に状態を更新する。
旧画像・旧保存データは新しい表示に流用しない。旧データの削除は行わない。

## 描画・追加

透過PNGを共通500×600座標上で配置する。描画順は羽、後ろ髪、基本パーツ、衣装、前髪、髪飾り。後ろ髪と前髪は同じ髪型選択から描画する。
長い髪は首・衣装を不自然に隠さないよう前後を分ける。長ズボンとブーツの衣装は裸足部分を隠す。
各パーツの画像と配置は `sprites.json`、名称・所有・店舗属性はカタログに定義。追加時はPNG、配置、カタログ項目を追加する。
出典と編集内容は `public/avatar/v2/SOURCES.md` を参照。

## 検証

`node scripts/test-wardrobe.cjs` で1,848通りのパーツ・色の変更、他カテゴリの維持、購入前制限、無料購入、初期所持品、所有判定、保存復元、位置調整、素材参照を検証。
型チェックと変更対象のESLintを実行。独立プレビューで3店の吹き出し、衣類店のみの試着室、無料購入、保存、クローゼットへの反映を操作確認する。

## 見た目の微調整

髪型・髪飾り・衣装・羽のカテゴリ選択中、左側に上下2単位ずつの調整と2%ずつの拡大縮小を表示する。上下の範囲は共通座標で−150〜150、サイズは70〜130%。画像は即時反映し、「調整を決定」で選択中のパーツの調整を保存する。「この姿に決定する」では姿と未保存の調整をまとめて保存する。「元に戻す」は上下0・サイズ100%に戻すプレビューで、決定すると保存される。試着をリセットは保存済みの姿・調整を復元する。
保存は `Wardrobe.adjustments`。髪は `hair:<item>`、衣装は `outfit:<item>`、羽は `wings:<item>`、髪飾りは `accessory:<hair>:<item>`。サイズは各キーに `scale:` を付ける。髪色変更は調整に影響しない。基本パーツ・飾りなしには調整操作を出さない。未購入パーツの調整も試着室で保存可能で、所有権は付与しない。
上下に大きく動かしたパーツを含めて合成表示の高さを計算し、見切れを防ぐ。アバタール下の名前表示は削除済み。
初期素材は `public/avatar/v2/starter-atlas.png` と `parts/*-starter-*.png`。再抽出は `node scripts/prepare-avatar-starter.cjs`。全体再生成時は旧シート処理の後に初期素材処理も実行する。

## 初回購入の確認用リンク

`http://localhost:3001/?entry=shops&scenario=first-closet` は専用の確認用保存領域を使う。購入後は `http://localhost:3001/?entry=closet&scenario=first-closet` で初期所持品を確認できる。従来のプレビュー保存領域は保持する。

## 妖精の部屋との連動

### 位置・サイズ調整の追加

基本パーツ以外（髪型・髪飾り・衣装・羽）は上下2単位ずつ、大きさ2%ずつで調整できる。大きさは70〜130%。各パーツの中心を基準に縦横比を保って拡大縮小する。「調整を決定」は選択パーツの上下位置とサイズを保存。「この姿に決定する」は姿と調整をまとめて保存。「元に戻す」は上下0・サイズ100%へ戻すプレビューで、保存には決定が必要。

既存の上下位置キーを保持し、サイズは `scale:<位置キー>` にパーセント値を追加。古い保存データにサイズがなければ100%。髪飾りはサイズも髪型との組み合わせごとに記憶する。拡大した羽などの左右のはみ出しも表示範囲に含める。

初期ショート髪の標準配置は幅270・高さ225・y=55へ変更。「木のうろのおうち」の表示は削除済み。

確定した姿と上下位置は共通の `useWardrobe(uid)` で部屋・自律移動キャラクターに反映する。`wardrobe-updated`（同じ画面）と `storage`（別タブ）を購読する。試着中の選択は反映しない。
店舗と冒険素材・コインの接続確認は `node scripts/preview-wardrobe.cjs --port=3002` → `http://localhost:3002/?entry=room`。商品の設定・価格・効果・買取については [店舗・買取・冒険素材の設定資料](shops/README.md) を参照。
