## 最初に押さえること

- 本体は `app/[locale]/page.tsx`。`/world` と `/avatar` は別の試作です。試作の +10pt / +30XP を本体の習慣報酬と混同しないでください。
- 本体の習慣は基本 +1pt。3日連続の個別習慣ボーナスは +5pt。累計3日ログインの +30pt とは別です。4日専用のボーナス定義はありません。
- AP は冒険専用です。総合ポイントに加算されません。購入・通貨消費・商品価格・宝の地図の効果は未実装です。
- データの存在だけでは「表示される」「獲得できる」と判断しません。セリフの未接続カテゴリ、全達成ボーナスの `maxStreak` 更新欠落も記録しています。

## 状態表記と根拠の読み方

| 状態 | この資料での意味 |
| --- | --- |
| 実装済み | 現在の対象画面から定義・処理への接続が確認できる。運用環境での動作保証ではない |
| 一部実装 | データや画面・関数はあるが、本体接続や必要処理に不足がある。独立試作も範囲を明記 |
| 未実装 | 調査した現行ソースに機能の処理がなく、準備中の表示などがある |
| コード上では確認できない | 将来仕様、過去の運用、デプロイ、実データなどをソースから判断できない |

本文のパスはプロジェクト直下からの相対表記です。エディターでそのパスを開き、記載の関数名・配列名を検索してください。各章末の「コード参照」は資料から開けるリンクです。行番号は調査時点の補助情報で、編集後は関数名を優先します。コード参照リンクは調査した作業フォルダの絶対パスです。別の場所へプロジェクトを移す場合はリンクの先頭パスを置き換えるか、表の相対パスから開いてください。
