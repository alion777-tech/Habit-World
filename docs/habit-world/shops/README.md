# 店舗・買取・冒険素材の設定資料

このフォルダーの **Markdown表のセルを書き換えるとアプリの設定に反映**されます。JSONやプログラムを直接編集する必要はありません。各表の見出し・列の順番・半角の `|` はそのままにしてください。本文の説明はプログラムの命令として扱いません。

## 編集する表

| 設定表 | アプリに反映される内容 |
| --- | --- |
| [エルフ店](elf.md) | 回復薬などの商品・価格・効果・販売状況 |
| [ドワーフ店](dwarf.md) | 冒険装備の商品・価格・効果・販売状況 |
| [妖精店](fairy.md) | クローゼット・着替えパーツの商品名・価格・販売状況 |
| [素材の買取](buyback.md) | 店舗ごとの素材買取単価・買取状況 |
| [冒険素材](materials.md) | 素材名・採集場所・獲得個数の範囲 |

通貨は専用コイン。EXPやAPは支払いで減りません。初期コインは0で、冒険素材を売って入手します。今回の衣類・クローゼットは0コイン、回復薬・冒険装備・買取単価は変更可能な仮設定です。

## 反映の手順

1. 表を編集して保存します。たとえば森のしずくの価格を `10` → `15`、効果量を `20` → `30` にします。
2. `npm run dev` で動かしている開発画面では保存を監視し、設定を再生成します。画面を再読み込みしてください。
3. 独立プレビューの `node scripts/preview-wardrobe.cjs --port=3002` でも設定表を監視します。画面を再読み込みして確認できます。
4. 手動反映は `npm run shops:sync`。公開版は `npm run build` の前に自動反映されます。公開中のサイトへの反映には再ビルド・再公開が必要です。

値が不正な場合はターミナルに理由を表示し、前回の有効な設定を維持します。生成先 `data/shop-catalog.json` は直接編集しません。

## 商品列の意味

| 列 | 設定方法 |
| --- | --- |
| ID | 保存データの識別子。追加時は新しい英数字ID。既存商品のIDは変更しません。 |
| 商品名 | 画面に表示する名前。 |
| 種別 | `consumable`＝消耗品、`equipment`＝冒険装備、`avatar`＝着替えパーツ、`closet`＝クローゼット。 |
| 価格 | 0以上の整数。0なら無料。 |
| 効果 | 下表の対応済み効果を指定。 |
| 効果量 | 回復量や加算値。0以上の整数。 |
| 対象 | 着替えパーツは既存の `カテゴリ:パーツID`。それ以外は `-`。 |
| 販売中 | `yes`＝販売、`no`＝販売停止。 |
| 説明 | 商品の説明文。効果量は画面で自動表示されるため、説明に数値を重ねなくても構いません。 |

## 動作する効果

| 効果 | 対応種別 | アプリ内の動作 |
| --- | --- | --- |
| `health` | consumable | 所持品で使用すると体力を回復。上限100。1個消費。冒険中・満タン時は消費しない。 |
| `adventure-ap` | equipment | 装備して出発した冒険の獲得APに加算。 |
| `material-bonus` | equipment | 装備して出発した冒険の素材獲得数を、素材の種類ごとに加算。 |
| `none` | avatar / closet | 着替えパーツ、またはクローゼット解禁。 |

冒険装備は1つだけ装備でき、外見の衣装とは別です。出発済みの冒険は出発時の結果を保持します。新しい種類の効果（戦闘ダメージや状態異常など）は、表の追加だけでは動かず、対応する処理の追加が必要です。

## 入れ替え・追加

- 販売を止める商品は行を削除せず `no` にします。以前買った消耗品は使用でき、装備も保持されます。
- 回復薬や冒険装備は、対応する種別と効果で行を追加すれば使えます。
- 着替えパーツは妖精店の表で管理します。新しい絵の追加にはPNGと `sprites.json` の配置・パーツ登録が必要です。既存パーツの価格・名前・販売停止は表だけで変更できます。
- 新しい素材は素材表に追加し、買取表に店舗・素材ID・単価を追加します。現在対応する採集場所は `forest` です。
- 買取中を `no` にすると売却できなくなります。売却は指定個数を減らし、単価×個数のコインを加算します。
- 表の更新で既存IDを別の商品へ使い回さないでください。獲得履歴や装備がそのIDを参照しています。

## 妖精の部屋との接続と保存

部屋→冒険→帰還で素材を獲得。部屋→アイテムショップ→各店舗の「素材の買取」でコインへ交換。「商品」で購入し、「所持品」で使用・装備できます。試着室は妖精店のみです。

ログインした本体では `users/<uid>.fairyRoom` のコイン・素材・所持品・購入履歴をFirestoreの同一トランザクションで保存します。失敗時にコインだけ減ったり素材だけ消えたりしません。同じ取引番号の直近200件の再送は二重処理しません。既存の本人用保存権限を使用し、ルールや公開環境は変更していません。

「この姿に決定」で外見と上下調整をブラウザー内のアカウント別データに保存し、部屋の妖精と自律移動キャラクターに即時反映します。試着中の姿は反映しません。外見の端末間同期は今回の対象外です。

## 接続確認画面

`http://localhost:3002/?entry=room`。実際のアカウントから分離した確認用保存です。「冒険をすぐ帰還させる（確認用）」で待ち時間を省けます。「動く妖精を表示」で着替え連動を確認できます。本体の冒険時間は24時間です。

検証: `node scripts/test-shops.cjs`、`node scripts/test-fairy-room-actions.cjs`、`node scripts/test-fairy-room.cjs`、`node scripts/test-wardrobe.cjs`。
